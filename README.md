# 📊 ApexWallet — Personal Finance & Analytics Dashboard

ApexWallet is a sleek, dark-themed personal finance dashboard built with **React JSX** and **pure, native CSS**. It features real-time metric tracking, interactive data visualization, budget category breakdowns, financial goal progress monitoring, and a realistic metallic Visa card widget.

## ✨ Features

- **Pixel-Perfect Dark Theme UI:** Designed specifically for high contrast, modern desktop screens ($100\text{vh}$ layout with zero scrolling).
- **Synchronized KPI Metrics:** Real-time tracking of Total Balance, Monthly Income, Expenses, and Savings.
- **Realistic Money Flow Chart:** Visual dual-bar chart mapping monthly cash flow ratios.
- **Budget & Savings Goals Tracker:** Dynamic progress bar indicators across expense categories and financial savings targets.
- **Recent Transactions Ledger:** Detailed breakdown of payment activity with category badges.

---

## 🛠 Tech Stack

- **Frontend:** React.js (JSX)
- **Styling:** Native CSS3 (Flexbox & CSS Grid)
- **Build Tool:** Vite
- **Icons & Fonts:** Inter Font Family & Unicode Glyphs
